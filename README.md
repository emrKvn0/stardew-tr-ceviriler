# Stardew Valley Mod Türkçe Çevirileri

Stardew Valley 1.6 modları için hazırlanmış / tamamlanmış Türkçe (`tr.json`) çeviri yedekleri.

## İçerdiği Modlar
- **ExtraMachineConfig** (`i18n/tr.json`)
- **Machine Control Panel** (`i18n/tr.json`)
- **Smart Building** (`i18n/tr.json`)
- **More New Fish (`[CP] New Fish`)** (`i18n/tr.json`)
- **[MFM] More New Fish (`[MFM] New Fish`)** (`i18n/tr.json`)
- **Bigger Backpack** (`i18n/tr.json`)
- **Harvest With Scythe** (`i18n/tr.json`)
- **Cornucopia - More Crops** (`i18n/tr.json` — eksik 1.6 satırları tamamlandı)
- **Cornucopia - More Flowers** (`i18n/tr.json` — eksik 1.6 satırları tamamlandı)
- **Happy Birthday (`[CP] HappyBirthdayContentPack en-US`)** (`ModAssets/Strings/` — Misc, Mail, Events ve 34 NPC diyaloğu)

## Kurulum (Modlar Güncellendiğinde Geri Yükleme)
1. Bu depodaki `Mods` klasörünün içindekileri kopyalayıp oyunun `Stardew Valley\Mods` klasörüne yapıştırın ve **"Hedefdeki dosyaları değiştir"** deyin.
2. Veya PowerShell ile doğrudan `.\kur.ps1` çalıştırın.
